## Live Demo

## About the Project

IRP LMS is a responsive Learning Management System website developed using HTML5 and CSS3. It provides a simple interface for learners to explore learning resources, watch video tutorials, and contact the support team.

## Features

- Responsive homepage with a learning journey section.
- Courses page featuring nine video tutorials.
- Contact page with contact information and an enquiry form.
- Common navigation bar and footer across all pages.
- Responsive design for desktop, tablet, and mobile devices.

## Technologies Used

- HTML5
- CSS3

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server or your web browser.
